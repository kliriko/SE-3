Демонстрація IDOR для запису на дисципліну

Є лише два предмети: один відкритий для запису, інший закритий. Через звичайний інтерфейс на закритий предмет записатися не можна.

У незахищеній версії сервер все одно приймає прямий URL із внутрішнім disciplineId. У захищеній версії той самий запит блокується.
